Save from anywhere

This Chrome extension sends pages, images, links, and selected text into this rebuild preview. Captures stay in this browser profile.

Download capture extension ↓
  1. Extract the ZIP.
  2. Open chrome://extensions and switch on Developer mode.
  3. Choose Load unpacked and select the extracted savers-rebuild-capture folder.
  4. Keep the rebuild preview open in a tab while you browse.

Click the extension icon to save a page. Right-click an image or link to save it. Select text and use the small Save text button or its right-click action. The confirmation offers Undo and Edit.
