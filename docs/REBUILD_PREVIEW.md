# Rebuild preview: review slice

The interactive preview lives on a separate Railway service at [savers-rebuild-preview-production.up.railway.app](https://savers-rebuild-preview-production.up.railway.app). Its source is the `rebuild` branch. The current Savers service continues on `main`.

## Available for review

- Responsive Library with all 815 exported bookmarks, search across titles, domains, notes, and tags from the expanding bottom dock, an expandable type filter with real social-source subfilters, a Favorites filter, export-order sort, grid/list views, and progressive card rendering. The type strip fades at its scroll edge.
- Collection browser and nested navigation using the names, hierarchy, and counts from the user's Savers screenshots. Links, Images, Smart collections, and Tags are separate views. Collections use wide, single-row previews with an owner badge and exported thumbnail when available; opening one reveals its child folders and items. Collection choices sit at the upper left, actions at the upper right. Tags use the page's natural scroll and can be searched from the dock.
- Bookmark cards open the original link as their primary action. A hover/touch action row opens Savers details, favorites the item, edits its tags, or changes its local privacy state. Detail has source, collection, clickable tags, notes where present, and vertically stacked related cards ranked by collection, source, tags, and title words. “More related” opens a feed with All, Yours, and Others scopes. Selection mode supports moving several own cards into a collection and is ready to save public cards from others into the browser preview. Others stays empty until public cards from other Savers accounts are connected; the preview does not invent those users or cards.
- Save forms and item details open as overlays in the current light or dark mode, preserving the view beneath. A direct `?item=bookmark-ID` visit opens the item as a standalone page. The detail gives the saved URL a visible “Visit saved link” action; the upper-right icon remains available. Full-height detail and related views scroll to the viewport edge without a page mask. The tag editor's actions are centered pills.
- Quick create for links, notes, collections, images, and small files, with a private/public choice. These edits persist in the current browser via localStorage; uploaded file data is kept there as well.
- Light and dark appearance modes with the supplied OM Bauer Folio Book weight, three type sizes, and neon green action color. Ordinary pills and icon controls use a shared 52 px height, neutral surface, hover tint, and active green; the dock uses a larger 76 px destination scale with equal inner gaps and outer padding. Contained scroll areas fade at an edge only when more content lies beyond it. Page, search, menu, and detail transitions respect reduced-motion settings.
- Discover has Discover/Following views and All/Yours/Others public-card scopes. Its selection mode can organize one's own public cards, and the card and profile controls are ready to follow and save cards from another account when one is connected. Inbox has active Activity, Following, Subscriptions, and Review views. Review uses real unsorted records; Subscriptions accepts and removes user-added site or feed URLs in browser storage. There is no Staff picks view.
- The account menu opens a centered browser-local profile with All cards and Collections shortcuts. A Following row opens a themed, scrollable overlay. It lists accounts followed in this browser when connected public accounts exist; another user's following list displays an availability message until account graph data is connected. Other users' profiles place Follow at the top right.
- The main Library and Discover surfaces are wider, with two roomy card columns, larger images, text beneath images, and a fade for long descriptions. The bottom destination dock is translucent with backdrop blur in both color modes.
- Library now offers S/M/L/XL thumbnail scales and selection for browser-local batch move, tag, or removal. A folder action on cards opens the searchable collection picker. Card details have editing for title, link, description, note, collection, and preview image; a small uploaded image or a drop onto a Library card can replace the preview locally. The detail menu also supports pinning, marking a link broken or working, and retrying an existing thumbnail. Duplicate saved URLs produce a notice. The page surface is 1.2% grey, the dock is centered, and active accents use the same bright green.
- Nested collection navigation and creation, with lock indicators. Smart collection rules can be tried and edited locally; the original rules were not part of the export. Image collections still need their own export to show actual image records.

## Scope of this preview

Starting collection names and counts are transcribed from the user's current Savers screenshots. The 815 bookmarks come from the user's CSV export, compressed into Railway-only environment variables by `scripts/prepare-rebuild-bookmarks.py`. The CSV and its generated chunks stay outside Git. The preview uses the export's already-generated, public Savers thumbnail URLs, loaded lazily in the browser. It does not generate previews or call an AI/metadata API. The supplied ZIP was too large for this workspace's 32 MB transfer limit; its local image files are not deployed. No production Supabase, Redis, storage, or worker credentials are configured on the preview service. `SAVERS_REBUILD_PREVIEW=1` rewrites `/` to `/rebuild` and returns 404 for the existing `/api/*` routes. `SAVERS_REBUILD_PASSWORD` protects the preview with HTTP Basic authentication, including fonts and static assets. Nothing saved in the preview appears in the current Savers app or on another device. The browser's storage limit makes this unsuitable for large uploads or long-term data storage.

The export has no visibility fields. The preview assumes items and collections are private until changed locally. Switching to public here does not create a share link or change production permissions. Discover and the browser-local profile can show cards made public in this browser. There are no connected accounts, so Others, other users' profiles, follower events, and the Following feed have honest empty states. The Follow button sits at the upper right of another account's profile when public account data is connected. Subscription URLs are stored locally but are not fetched as live feeds yet. Cross-account following and incoming follower events require isolated staging auth and data.

“Reload preview” retries the saved image URL with a fresh browser request. A genuinely new screenshot needs the original capture worker, which is not connected to this preview service. The editor's image URL and local upload provide a way to replace a missing or poor thumbnail now. The broken-link marker is a user-set review state; the preview does not run a background link check. Browser-local edits and removals do not change production data.

The complete feature and data parity work is laid out in [REBUILD_PLAN.md](./REBUILD_PLAN.md).

## Review tasks

1. Open the preview on desktop and phone. Review the real bookmarks, folder names, and hierarchy in Links, Images, and Smart collections.
2. Open a wide collection preview, then open a child folder. Check whether the hierarchy and spacing feel close to the references.
3. Browse Tags in Collections, edit tags from a card, and use the heart to add an item to Favorites. Reload and find it through the Library filters.
4. Use the plus button to save a link and write a note with tags. Reload and find them through dock search.
5. Switch between light and dark appearance in the account menu.
6. Open a card's Related section and its “More related” feed. Check the stacked layout and the honest empty state for Others.
7. In More related, select several of your cards and add them to a collection. Check the dock's spacing and the page transitions with and without reduced motion.
8. Check Discover and Inbox. Mark a card public locally to see it in Discover; try selection there. In Inbox, add and remove a subscription URL and open Review to inspect real unsorted cards. Activity and Following will be empty until account data is connected.
